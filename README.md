# Netflix Data Analysis

## Project Overview

This project performs exploratory data analysis on the Netflix titles dataset using Python.

The analysis explores Netflix movies and TV shows based on content type, release year, country, ratings, duration, and other attributes.

## Objectives

- Analyze the distribution of Movies and TV Shows on Netflix.
- Identify countries with the highest number of Netflix titles.
- Analyze Netflix content released over the years.
- Compare Movies and TV Shows.
- Analyze movie duration.
- Explore content ratings.
- Identify patterns and trends in Netflix content.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses the `netflix_titles.csv` dataset containing information about Netflix Movies and TV Shows.

Important columns include:

- Title
- Type
- Director
- Cast
- Country
- Release Year
- Rating
- Duration
- Listed In

## Analysis Performed

### 1. Movies vs TV Shows

Compared the number of Movies and TV Shows available on Netflix.

### 2. Content Released Over the Years

Analyzed how the number of Movies and TV Shows released changed over different years.

### 3. Top Countries

Identified countries contributing the highest number of Netflix titles.

### 4. Content Ratings

Analyzed the distribution of Netflix titles across different ratings.

### 5. Movie Duration

Analyzed the distribution of movie durations using a histogram.

### 6. Movie vs TV Show Comparison

Compared Netflix Movies and TV Shows using visualizations.
